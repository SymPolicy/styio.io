Data has a direction. Resources have a place. Intent has a shape. Styio makes them part of the language.

@stdin>>@stdout

Programs that move like data.

Built for data flows, resource topology, and pulse-driven computation. Connect streams directly and let the operators express the path.

@stdin >> #(n) => { fib(n) -> @stdout }

A small symbol. A clear intention.

Fewer natural language keywords. Direct operators that read like what they do. Send a value to an output with a single arrow.
