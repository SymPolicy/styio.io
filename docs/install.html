Set up Pafio and Styio

Pafio is the Cargo/CMake-style project entry. Styio is the system-provided compiler. Pafio never installs, updates, switches, or caches the compiler.

Quickstart

curl -fsSL https://styio.io/tools/pafio/install-pafio.sh | sh -s -- --base-url https://styio.io
pafio --version
styio --version

System Styio prerequisite

Install Styio through the system distribution available for your environment, then make styio available on PATH. This release does not create Homebrew, apt, or winget channels and does not publish a compiler installer here.

Pafio resolves the compiler in this fixed order: --styio-bin, PAFIO_STYIO_BIN, then styio on PATH.

Create and run a project

pafio new hello
cd hello
pafio build
pafio run
pafio test

The first workflow synchronizes dependencies and writes pafio.lock. Use --locked, --offline, or --frozen for reproducible execution.

Verify

pafio doctor
pafio metadata --json
pafio --json check

doctor diagnoses project, cache, registry trust, and external Styio capability. It does not repair or install anything.

Troubleshooting

Permission denied for /usr/local/bin

Install into a user-owned directory and add it to your shell PATH: 

mkdir -p "$HOME/.local/bin"
curl -fsSL https://styio.io/tools/pafio/install-pafio.sh | sh -s -- --base-url https://styio.io --install-dir "$HOME/.local/bin"

Inspect installer platform detection

Print the release platform key without installing: 

curl -fsSL https://styio.io/tools/pafio/install-pafio.sh | sh -s -- --print-platform

Styio is missing or incompatible

Install a compatible system compiler or point Pafio at an existing executable with --styio-bin or PAFIO_STYIO_BIN. Pafio fails closed when the required machine contract is unavailable.
