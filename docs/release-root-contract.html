Release contract

This is the static file layout consumed by the Pafio installer.

Release-root metadata

release-index.json
release-root.json
tools/...

release-index.json is the stable public index for the hosted service. release-root.json is generated inside each release-root bundle and records the deployment snapshot id, for example release-root-2026.05.09.1.

Pafio installer paths

tools/pafio/install-pafio.sh
tools/pafio/channel/latest/<platform>/version
tools/pafio/releases/<version>/<platform>/pafio
tools/pafio/releases/<version>/<platform>/pafio.sha256
tools/pafio/latest.json

Compiler distribution boundary

Styio is system-provided. Compiler binaries, channels, pins, and package-manager metadata are outside this release root and outside Pafio ownership.

Validation rules

  • Every channel pointer is a text file whose first field is a safe version segment.
  • Every binary has a sibling .sha256 text file.
  • Platform keys are safe, immutable path segments such as darwin-aarch64.
  • Release-root bundles are extracted into the Pages artifact, not committed to Git.
  • New release-root bundles include release-root.json metadata.
