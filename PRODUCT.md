# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

The public Styio website introduces the language, provides install documentation,
and hosts the static release root used by Pafio. The existing implementation is
static HTML, CSS, and JavaScript published through GitHub Pages.

## Users

Developers evaluating and installing Styio; operators publishing its release root.
These audiences are inferred from the existing website and documentation.

## Positioning

Styio is an experimental symbolic language for stream processing, resource
topology, and intent-driven execution, built on LLVM. It is in alpha.

## Capabilities and Constraints

Keep existing install commands, platform availability, documentation routes,
release contracts, code copying, and persistent light/dark preference. Preserve
existing in-progress Pafio and release publishing changes. No binary artifacts
or backend runtime data belong in the website redesign.

## Brand Commitments

The user selected experimental digital art: bold typography, symbolic
compositions, and fluid interactions, referencing Awwwards award winners.
The user rejected yellow-green and the wireframe manifold, and asked for a more
vivid, beautiful visual. Use cobalt, cyan, fuchsia and silver with substantial
sculptural material and expressive motion. Retain Styio's name and real language operators. English is the incumbent
content language. Home and documentation must feel like one product.

## Evidence on Hand

The current index.html and docs contain approved product content and install
instructions. The adjacent Styio repository README and example directory
contain language examples. No performance benchmarks or customer claims are
provided for this redesign.

## Product Principles

- Let the actual language explain its difference.
- Make learning and installing immediately reachable.
- Preserve readable content and working navigation without animation.
- Keep the static publishing model small and self-contained.
